О сайте

ByteFormatika — набор маленьких утилит: конвертер систем счисления, перевод римских цифр, работа с цветом, Base64, хэши, генератор паролей, Unix-время, регистр текста.

Всё работает в браузере. Никакой регистрации, рекламы, аналитики.

Конвертер систем счисления

  1. Введите число в поле «Число».
  2. Выберите основание в списке «Из системы».
  3. Выберите основание в списке «В систему».
  4. Результат появится автоматически.

Поддерживаются основания 2–36. Буквы A–Z обозначают 10–35. Пробелы и подчёркивания игнорируются. Используется BigInt — без потери точности.

История

Нажмите «💾 в историю» — текущий результат сохранится в браузере.

Клик по записи вернёт её в конвертер. Хранится до 30 последних записей.

Биты и байты

Введите любое значение — остальные пересчитаются мгновенно.

1 байт = 8 бит · 1 Кбайт = 1024 байта · 1 Мбайт = 1024 Кбайт · 1 Гбайт = 1024 Мбайт.

ASCII

Таблица символов 0–127. Клик по символу подставляет его в поле ввода конвертера.

Горячие клавиши

  • Ctrl / ⌘ + Enter — пересчитать.
